# TIC-TAC-TOE-Web-Application
# ❌⭕ Tic Tac Toe Web Application

An interactive Tic Tac Toe game built using HTML, CSS, and JavaScript. Play against another player or challenge the computer!

---

## 🚀 Features

* 👥 Player vs Player mode
* 🤖 Player vs Computer mode (basic AI)
* 🎯 Win and draw detection
* 🔄 Reset functionality
* 🎨 Clean and responsive UI

---

## 🛠️ How It Works

### 1. Game Board

* Dynamically generated 3x3 grid
* Each cell responds to user clicks

### 2. Game State Management

* Tracks current player (X or O)
* Prevents overwriting moves

### 3. Winning Logic

* Checks all possible winning combinations
* Ends game when a player wins or it's a draw

### 4. AI Opponent

* Random move selection from available cells
* Simple but functional gameplay
